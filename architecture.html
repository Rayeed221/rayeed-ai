Task isolation model

Session tasks (mic, send, receive, playback) are isolated from background tasks (telemetry, battery, position). A crash in one task group does not kill the other.

Key Design: Planner Authority

The Planner can override the LLM's next_action at any time for safety. The LLM suggests — the Planner decides. Non-blocking waits allow audio and telemetry to continue running during motor spin-up or altitude stabilization.
